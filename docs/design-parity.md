# 디자인 대조 (design parity)

기준: `reference/jnd_handoff/site/JND-A v4.dc.html` (A안 v4, 지정 1 · 옐로우 + 블랙). 구현: 이 저장소(`CONTENT_GATE=preview` 빌드 — 시안과 같은 자료 수로 비교). 캡처·비교 재현:

```bash
cd reference/jnd_handoff/site && python3 -m http.server 8080 --bind 127.0.0.1 &   # 기준 화면
CONTENT_GATE=preview npm run build && CONTENT_GATE=preview npx next start -p 3001 &
node scripts/parity-shots.mjs --impl http://127.0.0.1:3001     # reports/parity/*-ref.png, *-impl.png, shots.json
node scripts/parity-diff.mjs                                   # reports/parity/*-diff.png, diff.json
```

캡처 조건(기준·구현 동일): Chromium(Playwright 1.63), DPR 1, `ko-KR`, `prefers-reduced-motion: reduce`, 글꼴 로드 완료(`document.fonts.ready`) 후 전체 스크롤로 지연 이미지 로드, 모든 애니메이션·전환 정지(`animation-play-state:paused; transition:none`), 기준 화면은 검토용 상단 바 `display:none` + 헤더 `top:0`. 전화 순환은 기준이 방문마다 무작위 셔플이라 숫자 자체는 다를 수 있다(레이아웃 동일). 폭: 1440×900, 1024×768, 768×1024, 390×844 및 분기점 전후 1023, 1100, 560, 320.

## 1. 원본 판독 기록

- `:root` 기본값은 파란색이며 `applyPalette('지정 1 · 옐로우 + 블랙')` 이 덮어쓴다. 구현은 최종값을 `src/app/globals.css` `:root` 에 고정: `--blue #FED91B`, `--blue-600 #F2CB00`, `--blue-700 #DDB800`, `--blue-50 #FFF9DC`, `--blue-100 #FFF0A6`, `--blue-t #F07600`, `--ink #000`, `--on-accent #000`, `--on-dark #FED91B`, 밴드 선택 `#000/#FED91B`, 비선택 `rgba(255,255,255,.45)`, 버튼 그림자 rgb `254,217,27`. `::selection` 은 원본 그대로 파란 반투명.
- 글꼴 Pretendard Variable 1.3.9(dynamic subset), 아이콘 Lucide static 0.460.0, `word-break: keep-all`, 콘텐츠 폭 1120px, 좌우 `clamp(20px,4vw,40px)`, 섹션 `clamp(56px,8vw,104px)`, 반경 8/14/20/28, `--sh-*` 원본 복사.
- 반응형: 헤더·히어로·하단바 1024 분기, 부품 카드 4/2/1(1024/560), 6단계 6/3/2(1100/640), 작은 후기 2/1(560), 실적 로고 7/5/2(1100/700), 출장 목록 `columns:3 240px`, 데스크톱 푸터 `1.3fr 1fr .8fr 1.5fr` — 원본은 JS(`window.innerWidth`)로 계산하지만 구현은 같은 분기값의 CSS 미디어 쿼리(초기 HTML 에서 일치).
- 모션: `JNDDoorLoop`/`PieceCore` 이식(18.5초, 히어로 bare/cover, 종류 블록 contain, TYPE 01~03), 검정 오버레이 `.9 → .88(45%) → .35`, 인트로 700ms(reduced-motion 즉시), 화면 밖·탭 숨김 정지, reduced-motion·인쇄·정지 버튼은 17.2초 프레임. 문 종류 카드 키프레임 `dPen/dYL/dYR/dSw/dLed` 원본 복사.
- 원본 결함 1건: `jnd-core.js build()` 가 `symList/picks` 를 `home` 에 넣지 않아 시안 홈의 증상 진단 1단계 목록이 비어 있음(기준 캡처에서도 비어 있음). 구현은 7개 증상을 렌더한다(요구사항 명세의 3단계 요구).

## 2. 결과 (2026-11-04, `reports/parity/diff.json`)

`full` 은 전체 페이지 픽셀 차이(세로 오프셋이 생기면 그 아래 전부가 차이로 잡힘), `top900` 은 상단 0~900px 고정 영역(헤더 + 히어로/제목)만 비교한 값. 의도한 변경(아래 마스크)이 세로 오프셋의 원인이다.

분기점 전후(1023/1100/560/320) 결과는 같은 경향(`diff.json`). 홈 상단 고정 영역(헤더·히어로·전화 카드·배지)은 전 폭에서 0.3% 미만으로 4px 기준 안에 있다. 전체 페이지 기준으로는 의도한 변경을 마스크로 제외한 섹션별 비교가 필요하며, 아래 마스크 목록이 그 근거다.

### 의도한 변경 마스크 (비교 시 제외)

1. 검토용 바 제거·헤더 `top:0` (운영 화면).
2. 홈 01 증상 목록 렌더(원본 결함), 모션 정지 버튼(접근성).
3. 모든 하위 페이지의 빵부스러기(탐색경로·BreadcrumbList 구조화 데이터 요구).
4. 서비스 목록 카드의 작업 항목 태그, 시공사례·가이드 허브 소개 문단(얇은 본문 방지).
5. 운영 확인 대기 안내문(대리점·개인정보·테스트 접수) — 확인 후 사라짐.
6. 전화 순환: 셔플 없이 대표번호 첫 강조(초기 HTML 일치). 운영 게이트(`strict`)에서는 보조번호 확인 전 대표번호 1개.
7. 후기 사진: 운영 게이트에서는 실제 후기 사진 확보 전까지 사진 없이 표시(preview 는 시안과 같은 순환 사진).

### 수정한 결함

- 모바일(<1024) 헤더에 데스크톱 전화 버튼이 겹쳐 가로 넘침(390 → 466px)이 생기던 CSS 우선순위 문제 → `.header-contact` 에 모바일 `display:none!important` (상단 영역 diff 0.12%로 확인, 320px 폭 가로 넘침 0).
- 지연 로딩 이미지가 전체 캡처에 빠지던 문제 → 캡처 전 전체 스크롤로 로드.
