# 측정 대시보드 (2026-11-05)

수치는 모두 근거 파일(search-evidence.json rows)에서 계산한다. 콘솔 권한·등록이 없는 엔진은 "데이터 대기"이며 추정치를 넣지 않는다.

| 엔진 | 발행 | 색인 적합 | 색인 확인 | 미색인 확인 | 색인 미확인 | 실노출 확인 | 노출/클릭 | 판정 |
|---|---:|---:|---:|---:|---:|---|---|---|
| Google | 162 | 162 | 0 | 0 | 162 | 0/162 | — / — | 데이터 대기 |
| Naver | 162 | 162 | 0 | 0 | 162 | 0/162 (상위 30 URL 한정 — 나머지 측정 불가) | — / — | 데이터 대기 |
| Bing | 162 | 162 | 0 | 0 | 162 | 0/162 | — / — | 데이터 대기 |

정의
- 발행: contentStatus=PUBLISHED, indexEligibility=true 인 URL 수(사이트 빌드 포함).
- 색인 적합: 발행 중 indexPolicy=index 이고 사이트맵에 포함된 URL 수.
- 색인 확인: 엔진 콘솔 URL 검사에서 "색인됨"으로 기록된 URL 수(rows.state=indexed). 사이트맵 제출·IndexNow 통지는 색인 확인이 아니다.
- 실노출 확인: 해당 엔진 검색 실적에서 노출 1회 이상 기록된 URL 수. Naver 는 상위 30 URL 밖은 측정 불가.
- 판정: 색인 적합 URL 의 90% 이상이 실노출 확인되면 "달성 확인". 데이터가 없으면 "데이터 대기"(추정 금지).

- Google: 속성 권한 수령 전 — 데이터 대기. 근거 범위: Search Console URL 검사(저장된 색인 상태)·페이지 색인 보고서 / 검색 실적(웹, 페이지 기준) 노출 1회 이상
- Naver: URL 별 실노출은 상위 30 URL 밖이면 측정 불가. 근거 범위: 서치어드바이저 URL 검사(수동) · 사이트 진단 총량 / 콘텐츠 노출·클릭 — 클릭 상위 30 URL 만 제공
- Bing: 사이트 추가·IndexNow 키 등록 전 — 데이터 대기. 근거 범위: Webmaster Tools URL Inspection · Site Explorer / Search Performance(Web, Pages) 노출 1회 이상

## 300 URL 목표 대비

- 색인 적합 URL: 162개. 목표 300 의 90%(270) 를 충족하려면 **색인 적합 URL 자체가 270개 이상이어야 하며**, 현재 근거로는 162개까지만 발행 가능하다(강화도어 57 미확인, 지역 센서·모터 110 통합, 사례 5 검수 대기). 따라서 "300개 중 90% 상위 노출"은 현재 상태로는 달성 불가이며, 달성 가능 상한은 발행 162개 기준 90% = 146개 실노출이다.
- 숫자를 늘리기 위한 지역 변형 URL 추가는 하지 않는다. 보류 URL 은 운영자 사실 확인(강화도어)·지역 고유 근거(사례 사진·출장 기록) 확보 시 다시 심사한다.
